# Холодильник

Небольшая консольная программа на Python для учёта продуктов и проверки их
срока годности. Данные хранятся в памяти и очищаются после выхода из программы.

## Запуск

Нужен Python 3.9 или новее. Дополнительные библиотеки не требуются.

```bash
python main.py
```

## Возможности

- показать продукты и их сроки годности;
- добавить продукт;
- удалить первый продукт с указанным названием;
- отметить продукты с истёкшим сроком годности.

Дату вводите в формате `ГГГГ-ММ-ДД`, например `2026-12-31`.
